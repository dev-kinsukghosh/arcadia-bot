# Change Log — 11-2026

### 01-11-2026

- **Towny Multi-Entity Compare (Towns & Nations, Min 2, Max 4)**:
  - Enhanced `/towny compare` (`src/commands/general/towny.js`) to support comparing both towns and nations with 2 to 4 targets simultaneously.
  - Added `type` command option with choices `Towns` (`town`) and `Nations` (`nation`), followed by `target1` (required), `target2` (required), `target3` (optional), and `target4` (optional).
  - Dynamic Autocomplete Routing: Enhanced `autocomplete` in `src/commands/general/towny.js` to intelligently suggest either active towns or nations depending on the chosen `type`.
  - Comprehensive Validation:
    - Enforces a minimum of 2 entities to compare with clear ephemeral error feedback.
    - Enforces a maximum of 4 entities via slash command options.
    - Validates target entity existence in the Towny API dataset with specific error reporting for missing names.
    - Prevents duplicate comparisons (comparing the same town/nation with itself).
  - Multi-Entity Canvas Comparison Chart Engine:
    - Upgraded `drawCompareChart` in `src/utils/canvasGraph.js` to handle 2, 3, or 4 entities for both towns and nations.
    - Extended 2-item comparisons with customized telemetry for nations (King, Capital, Member Towns count, Total Residents, Total Chunks, and Towns Count Ratio bar).
    - Introduced a responsive 3-panel and 4-panel multi-card layout with individual telemetry cards (Badge, Name, Leader, Population, Territory/Towns, Capital/Nation, PVP indicator) and dual stacked comparative distribution bars (`POPULATION DISTRIBUTION` and `TERRITORY CHUNKS / MEMBER TOWNS DISTRIBUTION`) with exact percentages and color legends.
  - Rich Discord Embed & Navigation:
    - Dynamic side-by-side embed fields formatted per entity with color-coded badges (`🟦`, `🟩`, `🟪`, `🟧`).
    - Comparison summary section highlighting the head-to-head population and territory/towns leaders.
    - Interactive ActionRow with up to 4 quick-inspection buttons (`nav_town` or `nav_nation`) plus a Web Dashboard direct link button (max 5 buttons per Discord row).
    - Integrated with `initNavState` for contextual in-embed back navigation.
  - Updated `/help` metadata in `src/commands/general/help.js` to accurately detail 2-4 entity comparisons for towns and nations.
- **Towny Top Chart & Canvas Graph Engine Fixes**:
  - Resolved row clipping and canvas overflow in `drawTopChart` (`src/utils/canvasGraph.js`) where bottom rows (#9 and #10) extended beyond canvas bounds and collided with the branding footer due to an erroneous `(rowHeight + gap)` step offset.
  - Implemented dynamic canvas sizing and comfortable 36px row pitching to guarantee all top 10 items render with spacious breathing room.
  - Added custom rank badge pills (`#1` Gold, `#2` Silver, `#3` Bronze, `#4+` Slate) and auto-fitted town/nation labels using `drawFittedText` to prevent text bleeding into margins.
  - Revamped value text positioning: dynamically measures text and positions inside the active bar when wide enough, or outside with dedicated margin spacing when narrow, eliminating text clipping and overlapping.
  - Fixed unicode emoji slicing bug in `/towny top` (`src/commands/general/towny.js`) by replacing fragile `title.substring(3)` calls with explicit titles and regex emoji trimming.
  - Improved column alignment in Discord `/towny top` monospace embeds using dynamic label padding based on longest town/nation names.
  - Added a direct Web Dashboard link button component (`Open Towny Towns/Nations Web Monitor`) on `/towny top` replies.
  - Added PVP status indicators to 2-entity comparison panels in `drawCompareChart` for consistency with multi-entity cards.
  - Hardened `drawHistoryLineChart` against title collision with legend labels and resolved duplicate rounded Y-axis ticks on low-range integer charts.

- **Interactive Tools & Utilities Suite (/tools)**:
  - Added a new first-class web dashboard section `/tools` (`dashboard/src/components/ToolsMonitor.vue`) complete with desktop and mobile navbar navigation buttons.
  - Multi-Entity Town & Nation Comparator (matching Discord `/towny compare`):
    - Supports comparing 2, 3, or 4 towns or nations simultaneously side-by-side.
    - Searchable modal entity pickers with instant name filtering.
    - Side-by-side comparison cards with entity badges (#1 Blue, #2 Emerald, #3 Purple, #4 Amber), mayor/king player head avatars, resident populations, territory chunks & capacity utilization, nation affiliations, PVP mode indicators, and joining policies.
    - Segmented visual distribution progress bars for Population Distribution and Territory Chunks/Towns Distribution with detailed percentage legends matching the bot canvas engine.
    - Quick presets for Top 2, Top 4, and target slot swapping.
  - Multi-Currency Cross-Comparator (matching Discord /ccompare):
    - Compare 2 to 5 nation currencies side-by-side.
    - Displayed live exchange rates, base backing, backing standard items, and clean 24h trend percentages limited to a maximum of 3 decimal places (eliminating unrounded float values).
    - Removed unpopulated zero-value telemetry fields (circulating supply and reserve value).
    - Dynamic cross-currency exchange matrix table calculating instant direct conversions.
  - UI Cleanup, Performance & Animation Enhancements:
    - Removed non-dashboard civic calculators (council seat allocator and arbitrage deals) and hid unreleased town upkeep simulator to prevent 403 authorization rejections.
    - Streamlined component footprint by removing unused convoy and shops stores, trimming bundle size by 22 kB.
    - Added CSS transitions (card-switch) for smooth tab toggling and modal-box-anim pop-in animations for the entity picker dialog.
    - User Option Persistence: Persisted last active tool tab, comparison target type, entity counts, targets, and selected currencies in localStorage.
    - Header UI & Layout Polish: Cleaned badges (replaced Live Tools with Tools, removed Arcadia Community Suite), fixed text overflow on summary metric counters with responsive 3-column grid, and resolved town/nation appear-fade animation glitch.
    - Card & Table Text Overflow Fixes:
      - Shortened verbose labels (`Nation Affiliation:` to `Nation:`, `Capital Town:` to `Capital:`, `Claim Capacity:` to `Claims:`, `Diplomatic Allies:` to `Allies:`, `Security Mode:` to `Security:`, `Joining Policy:` to `Policy:`).
      - Added truncation, `min-w-0`, and tooltip title attributes to entity names, mayor/leader tags, currency names, nation labels, and backing items across all card widths.
      - Fixed comparative distribution bar legends with `max-w-[130px]` truncation and non-shrinking stats labels to prevent multi-column breakages.
      - Applied `whitespace-nowrap` to table headers and data cells in the Cross-Currency Direct Conversion Matrix to preserve clean tabular layout with horizontal scrolling.
      - Added `min-w-0` and truncation guards to Target Picker modal search results to eliminate modal horizontal stretching.
      - Resolved text and box overflow on Discord slash command tab badges (`/towny compare` and `/ccompare`) by implementing `inline-flex shrink-0 items-center whitespace-nowrap`, wrapping inner labels in `truncate min-w-0`, and structuring the tab container with responsive flex stretching (`flex-col sm:flex-row max-w-full`).
  - Route & SSG Prerendering Integration:
    - Registered `/tools` route in `dashboard/src/router.js`.
    - Included `/tools` in `dashboard/prerender.mjs` SSG prerendering build pipeline (`tools.html`).
    - Registered newly required FontAwesome icons (`faWrench`, `faCodeCompare`, `faBuildingColumns`, `faChartPie`, `faTags`, `faHourglassHalf`, `faCopy`, `faArrowRight`) in `dashboard/src/main.js`.
